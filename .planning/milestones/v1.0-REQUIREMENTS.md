# Requirements

## Epic: hCaptcha Flask API

### Core Capabilities
- Implement a Flask application running a simple HTTP server.
- The server must receive POST requests with:
  - Base64 encoded image data or image URL.
  - A challenge prompt text.
- The application should wrap the `hcaptcha-challenger` core solving agent to process the image and prompt.
- The response must return a structured JSON containing the predicted click coordinates.

### Technical Constraints
- The API is for local/internal usage. No authentication required.
- Do not implement end-to-end browser automation within the API.

### Definition of Done
- A `server.py` or equivalent module exists to run the Flask application.
- Optional dependencies in `pyproject.toml` are updated to support Flask.
- The server can successfully receive an image and a prompt and return a valid response format.
- Code matches the existing linting and formatting rules of the project.
