# Roadmap

## Phase 1: Setup API Foundation
**Goal**: Integrate Flask into the project and establish the basic API server skeleton.
**Requirements**: Epic: hCaptcha Flask API

### Plans
1. Update `pyproject.toml` to add `flask` as an optional dependency (replacing or adding alongside existing ones).
2. Create the entry point for the Flask application.
3. Establish a simple health-check endpoint.

## Phase 2: Implement Solver Endpoint
**Goal**: Build the POST endpoint to receive images and prompts and return LLM solver coordinates.
**Requirements**: Epic: hCaptcha Flask API

### Plans
1. Create a `POST /solve` endpoint that accepts multipart form data (image) and form fields (prompt) or JSON with base64.
2. Wire the endpoint to the `hcaptcha-challenger` internal solver agent.
3. Format the solver results into a standard JSON response containing click coordinates.
4. Add basic error handling for invalid requests.
