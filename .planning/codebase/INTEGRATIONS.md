# Integrations

## External Services & APIs
- **hCaptcha Services**: Core target for the agent solver.
- **LLM Providers**:
  - Google GenAI (Gemini models)
  - OpenAI (GPT models)
  - OpenRouter (used in e2e tests)
- **Browser/Environment Modifiers**: Camoufox (for anti-bot evasion and fingerprinting).

## Optional Integrations
- **FastAPI**: Can serve as a standalone server or REST API wrapper around the challenger.
