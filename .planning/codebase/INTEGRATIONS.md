# Integrations

## External APIs & Services
- **Google GenAI API**: Used for multimodal language model capabilities to solve complex captchas.
- **hCaptcha**: The primary target service this tool interacts with and solves challenges for.

## CI/CD & Automation
- **GitHub Actions**: 
  - `sentinel.yaml`: Automated sentinel tasks.
  - `collector.yaml`: Automated data collection.
  - `python-pytest.yaml`: Continuous integration and testing.
  - `publish.yaml`: Automated publishing and release.

## Datasets & Model Hubs (Referenced)
- **Roboflow**: Used for dataset version control system (VCS) and annotations.
- **GitHub Releases**: Used for hosting and downloading model assets (`hcaptcha-challenger/releases/tag/model`).

*(Note: The `archive` component has been explicitly excluded from this map.)*
