# Tech Stack

## Core Languages
- **Python**: 3.10+ (Primary implementation language)

## Frameworks & Libraries
- **Browser Automation**: `playwright`, `camoufox`
- **Computer Vision**: `opencv-python`, `pillow`, `matplotlib`
- **LLM Integration**: `google-genai`, `openai`
- **CLI Framework**: `typer`
- **Web Server** (Optional): `fastapi`
- **Configuration & Validation**: `pydantic-settings`
- **Logging**: `loguru`
- **Network**: `httpx[http2]`
- **Event Management**: `pyee`
- **Data Serialization**: `msgpack`

## Build & Tooling
- **Package Manager / Build System**: `uv`, `hatchling`
- **Linter / Formatter**: `ruff`, `black`
