# Project: HumanCursor Integration

**Status:** Initializing
**Owner:** Gemini CLI
**Date:** 2026-05-01

## Goal
Replace the existing human-like cursor movement algorithm in `hcaptcha-challenger` with the `HumanCursor` library from `https://github.com/riflosnake/HumanCursor`.

## Context
- **Project:** hcaptcha-challenger
- **Constraint:** Complete removal of the current algorithm.
- **Reference:** [HumanCursor GitHub](https://github.com/riflosnake/HumanCursor)

## Success Criteria
- [ ] Current cursor movement logic is identified and removed.
- [ ] `HumanCursor` is integrated as a dependency.
- [ ] Trajectories generated by `HumanCursor` are used for hCaptcha interaction.
- [ ] Performance and "human-likeness" verified through existing or new tests.
